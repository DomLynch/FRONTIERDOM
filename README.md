# FRONTIERDOM

A mobile web trading and management game using PlayCanvas. Start as a small independent operator with one worn freighter, three crew and £25,000. Trade through an ancient gate network, take contracts, manage risk, and watch the consequences of tactical choices.

The prototype tests one question: **Do you want to make one more trade run?**
